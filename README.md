# Empirical Studies on Quantum Optimization for Software Engineering: A Systematic Analysis

This repository contains results of [extracted data](extracted_data.csv) for the study titled _Systematic Analysis of Empirical Studies on Quantum Optimization for Software Engineering_. 

Note that our paper discusses the 77 primary studies originally from [the latest data](https://github.com/WSE-Lab/QuantumOpt4SE/blob/main/data/updated_selection.csv) of a related [survey paper](https://dl.acm.org/doi/abs/10.1145/3816147).
